# Vercel Deployment Guide

This project is deployed on Vercel.

- **Production URL:** https://breathesafe-ai-env-platform.vercel.app
- **Preview URL:** https://breathesafe-ai-env-platform-7hm8ktbms-tejashree9340s-projects.vercel.app

## How to redeploy

```bash
# Install Vercel CLI if not already installed
npm install -g vercel

# Deploy (you will be prompted for login if needed)
vercel --prod --yes
```

Make sure to set the required environment variables in the Vercel dashboard:
- `OPENAQ_API_KEY`
- `S3_BUCKET_NAME`
- `AWS_REGION`

The frontend does not contain any authentication UI.
